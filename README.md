## 🛠️ Troubleshooting

**The tool will not open.**
Right-click the downloaded file and choose **Run as administrator**. If Windows still blocks it, check that your antivirus has not quarantined the file, and restore it if needed.

**The modules do not seem to do anything.**
Confirm that Transport Fever 3 is running and that you are inside an active save game, not sitting on the main menu. Then check that the specific module's toggle is switched on.

**The game crashes after enabling a module.**
Close the game, restart both the game and tf3-modkit, and enable modules one at a time to identify the culprit. Turning a single module off is usually enough to get back to normal.

**Nothing happens after an update.**
Revisit the download link and grab the newest version. Older builds can fall out of step with game updates.

**Windows Defender flags the download.**
This is common for small, unsigned community tools. Choose **More info → Run anyway** to proceed.
